# Εκτίμηση τιμής Imbalance / spread (Imbalance − DAM)

Κώδικας Python που εκτιμά ανά 15λεπτο την τιμή απόκλισης (imbalance) ή το spread
`imbalance − DAM` για την ελληνική αγορά, **πριν τη DAM** (η τιμή DAM της ημέρας-στόχου
θεωρείται γνωστή: πραγματική ή δική σας εκτίμηση). Είσοδοι:

* πρόβλεψη ΑΠΕ και φορτίου ΑΔΜΗΕ (αυτόματο κατέβασμα),
* ιστορικό **ευστάθειας**: ο ΑΔΜΗΕ βάζει μονάδες αερίου και περικόπτει ΑΠΕ για να έχει εφεδρεία,
* τιμές DAM (και IDA, αν η πρόβλεψη γίνεται αργότερα),
* ιστορικό imbalance (δημοσιεύεται με καθυστέρηση).

## Χρονισμός: τι είναι γνωστό τη στιγμή της πρόβλεψης

Προεπιλογή: η πρόβλεψη για την ημέρα D βγαίνει στη D-1 πριν τη DAM.

| Πληροφορία | Γνωστή έως | Πώς χρησιμοποιείται |
|---|---|---|
| Πρόβλεψη ΑΠΕ/φορτίου ΑΔΜΗΕ για τη D | D (ολόκληρη) | άμεσα |
| DAM της D | D (ολόκληρη) | στη στήλη `dam` (πραγματική ή εκτίμηση) |
| IDA | – | δεν χρησιμοποιούνται, εκτός αν δοθεί `--ida ida1 ...` |
| Ευστάθεια (πλεόνασμα ISP1) | D-1 (το ISP1 της X βγαίνει X-1 ~18:45) | ιστορικό + **πρόβλεψη** για τη D (`stab_prob`) |
| Περικοπή ΑΔΜΗΕ (`Curt_Flag`) | μαζί με τα imbalance | P(περικοπή \| πλεόνασμα) → `p_curt` |
| Imbalance | Κυριακή πριν την τελευταία Πέμπτη | ιστορικό spread (8–15 ημέρες πίσω) |

Τα imbalance δημοσιεύονται **κάθε Πέμπτη για την προηγούμενη Δευτέρα–Κυριακή**:

| Ημέρα έκδοσης | Τελευταία δημοσίευση | Imbalance γνωστό έως |
|---|---|---|
| Κυρ. 22/11 | Πέμ. 19/11 | Κυρ. 15/11 |
| Πέμ. 19/11 (πριν δημοσιευθούν) | Πέμ. 12/11 | Κυρ. 8/11 |
| Πέμ. 19/11 με `--pub-same-day` | Πέμ. 19/11 | Κυρ. 15/11 |

Οι κανόνες αυτοί εφαρμόζονται και στο backtest. Τα tests `test_no_leakage` και
`test_stability_history_lag` ελέγχουν ότι δεν περνά μελλοντική πληροφορία στις εισόδους του μοντέλου.

## Ευστάθεια και περικοπή

Όταν οι ΑΠΕ είναι πολλές και το καθαρό φορτίο χαμηλό, ο ΑΔΜΗΕ κρατά μονάδες αερίου σε λειτουργία
για εφεδρεία/ευστάθεια. Στο ISP1 αυτό εμφανίζεται ως **Energy Surplus < 0** (πλεόνασμα), και στον
πραγματικό χρόνο ο ΑΔΜΗΕ μπορεί να **περικόψει ΑΠΕ** (`Curt_Flag` στο IMBABE).

Πραγματικά δεδομένα, εβδομάδα 9–15/11/2026:

| Κατάσταση | 15λεπτα | Μέση τιμή imbalance |
|---|---|---|
| Χωρίς πλεόνασμα στο ISP1 | 573 | 261 €/MWh |
| Πλεόνασμα στο ISP1, χωρίς περικοπή | 65 | 355 €/MWh |
| **Περικοπή (Curt_Flag = 1)** | **35** | **−100 €/MWh σε όλα** |

Σχεδόν όλες οι περικοπές (34/35) έγιναν σε 15λεπτα πλεονάσματος του ISP1, αλλά μόνο περίπου
1 στα 3 15λεπτα πλεονάσματος κατέληξε σε περικοπή. Γι' αυτό ο κώδικας χρησιμοποιεί:

1. **Μοντέλο ευστάθειας** (ταξινομητής) → `stab_prob` = P(πλεόνασμα ISP στο 15λεπτο). Εισόδους έχει
   το μερίδιο ΑΠΕ (και το ημερήσιο μέγιστο), το καθαρό φορτίο (και το ημερήσιο ελάχιστο), τις ώρες με
   μερίδιο ΑΠΕ πάνω από 70%, το ημερολόγιο και το ιστορικό πλεονάσματος έως **D-1**.
2. **`p_curt`** = `stab_prob` × P(περικοπή | πλεόνασμα) των τελευταίων 28 γνωστών ημερών,
   δηλαδή η εκτιμώμενη πιθανότητα να πάει το imbalance στα −100.
3. **Κύριο μοντέλο** (quantile gradient boosting) για το spread. Παίρνει τα `stab_prob` και `p_curt`,
   καθώς και το ιστορικό spread μέσα/έξω από περιόδους πλεονάσματος. Στην εκπαίδευση το `stab_prob`
   υπολογίζεται out-of-fold, ώστε να μοιάζει με την ακρίβεια που θα έχει στην πράξη.

Επειδή στην περικοπή η τιμή «πηδά» στα −100, η κατανομή είναι δικόρυφη. Η διάμεσος (`spread_q50`)
μπορεί να μένει κοντά στο «κανονικό» επίπεδο, ενώ το `p_curt` και το `spread_q10` δείχνουν τον κίνδυνο.

Το backtest τυπώνει πίνακα **ευστάθεια → imbalance** ανά κλάση `stab_prob`: πραγματική συχνότητα
πλεονάσματος, πραγματική συχνότητα περικοπής, μέσο spread και P(imbalance < DAM).

## Αυτόματο κατέβασμα ΑΔΜΗΕ

```bash
python -m imbalance_forecast admie --start 2024-01-01 --out data/admie.csv
```

Επαληθευμένο σε πραγματικά αρχεία (API `getOperationMarketFilewRange`). Τα tests χρησιμοποιούν
δείγματα που βρίσκονται στο `tests/fixtures/`.

| Πηγή (κατηγορία ΑΔΜΗΕ) | Έκδοση | Τι γράφεται |
|---|---|---|
| `ISP1DayAheadLoadForecast` | **η τελευταία πριν το DAM gate** (v1 ~09:20 D-1) | `load_forecast` |
| `ISP1DayAheadRESForecast` | ίδια | `res_forecast` |
| `ISP1ISPResults` | τελευταία | `stability` = max(0, −Energy Surplus) MW |
| `IMBABE` (εβδομαδιαίο) | τελευταία | `imbalance`, `curt_flag` |

* Για τις προβλέψεις φορτίου/ΑΠΕ κρατάμε την έκδοση που υπήρχε πριν τη DAM (`--dam-gate 12:00`,
  τοπική ώρα D-1) και στο ιστορικό. Έτσι η εκπαίδευση βλέπει την ίδια ποιότητα πρόβλεψης με την παραγωγή.
* Τα αρχεία μένουν στο `data/raw/admie/` και ξανατρέχοντας την εντολή κατεβαίνουν μόνο τα νέα.
  Ανάμεσα στα αιτήματα γίνεται παύση 1 s (`--sleep`), για να μην επιβαρύνεται ο server.
* Τα υπόλοιπα πεδία (θερμικές μονάδες ISP, τιμές Energy Up/Down, απαιτήσεις aFRR/mFRR, απόκλιση
  συστήματος, τιμές mFRR) γράφονται στο `data/admie_extra.csv` για ανάλυση. **Δεν** δίνονται στο μοντέλο,
  γιατί δεν είναι γνωστά για την ημέρα-στόχο πριν τη DAM.
* `python -m imbalance_forecast admie-types` δείχνει όλες τις κατηγορίες και
  `admie-list --category X --date D` τα αρχεία μιας ημέρας.
* Η DAM **δεν** δίνεται από τον ΑΔΜΗΕ (είναι από το ΕΧΕ/HEnEx), οπότε τη δίνετε σε δικό σας CSV (`prices.csv`).

## Μορφή δεδομένων

Ένα ή περισσότερα CSV με κοινή στήλη `timestamp` (αρχή διαστήματος· χωρίς ζώνη = ώρα Ελλάδας·
με offset `+02:00/+03:00` = σωστά και στις αλλαγές ώρας).

```
timestamp,dam,ida1,ida2,ida3,imbalance
timestamp,load_forecast,res_forecast,stability,imbalance,curt_flag   <- από `admie`
```

* Οι ωριαίες σειρές επαναλαμβάνονται αυτόματα στα 15λεπτα.
* Ό,τι δεν έχει δημοσιευθεί (`imbalance`, `stability`) μένει κενό.
* Για την ημέρα-στόχο βάλτε στη στήλη `dam` την τιμή που γνωρίζετε/εκτιμάτε.
* Κάθε επιπλέον αριθμητική στήλη γίνεται feature `x_<όνομα>`. Πρέπει να είναι γνωστή στην έκδοση,
  δηλαδή πρόβλεψη και όχι πραγματική τιμή.

## Χρήση

```bash
pip install -r requirements.txt

python -m imbalance_forecast demo                     # συνθετικά (ψεύτικα) δεδομένα

python -m imbalance_forecast admie --start 2024-01-01 --out data/admie.csv

python -m imbalance_forecast backtest --data data/prices.csv data/admie.csv \
    --start 2025-10-01 --out backtest.csv

# πρόβλεψη για αύριο, πριν τη DAM (προεπιλογή)
python -m imbalance_forecast predict --data data/prices.csv data/admie.csv \
    --date 2026-11-23 --out forecast_2026-11-23.csv

# αργότερα, μετά το IDA1
python -m imbalance_forecast predict --data ... --date 2026-11-23 --ida ida1
```

Επιλογές: `--target spread|imbalance`, `--lead N`, `--ida ...`, `--pub-same-day`, `--window`,
`--stab-threshold`, `--retrain-every N` (backtest).
Για το `admie`: `--only`, `--sleep`, `--dam-gate`.

Έξοδος ανά 15λεπτο: `stab_prob`, `p_curt`, `spread_q10/q50/q90`, `imb_q10/q50/q90` (= DAM + spread),
`p_imb_gt_dam`, `p_imb_lt_dam`.

## Δομή

```
imbalance_forecast/
  config.py        ρυθμίσεις (χρονισμός, IDA, ευστάθεια, μοντέλο)
  availability.py  κανόνας «Πέμπτη -> προηγούμενη Δευ–Κυρ»
  admie.py         κατέβασμα/ανάγνωση αρχείων ΑΔΜΗΕ
  data.py          φόρτωση CSV, ζώνες ώρας, πλέγμα 15'
  features.py      features χωρίς διαρροή (as-of cutoffs)
  model.py         μοντέλο ευστάθειας + quantile GBM + ταξινομητής κατεύθυνσης
  pipeline.py      backtest, metrics, stability_report, forecast
  synthetic.py     συνθετικά δεδομένα για δοκιμές
tests/             pytest
```
